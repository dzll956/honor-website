01

打野到底该干嘛

打野是整个团队的节奏发动机，俗称"打野是爹"。你不是在刷野，你是在掌控整场比赛的走向。一个好的打野，能把队友从青铜带到王者；一个坑的打野，能把三个队友气到挂机。

🎯

掌控节奏

知道什么时候该刷野、什么时候该抓人、什么时候该开龙

节奏是关键！不是刷完野区就没事了，你要带着队友搞事情。比如你刷完红区，看上路压线了，那就去抓一波；中路有线权，就去入侵野区。节奏在你手里，不是等队友喊你。

⚡

带起节奏

主动找机会，不是等机会来，是你去创造机会

别等着队友喊"打野来抓人"，你要自己判断什么时候该抓。比如对面射手压线太深了，这就是机会；比如对面打野在下半野区，你就可以去上路搞事情。主动出击才能掌控比赛。

🗺️

地图意识

时刻关注小地图，知道对面在哪，你才好安排行动

小地图是打野的命根子！看到对面打野在中路冒头，说明他在上半野区；看到对面射手突然往后走，可能是有人来抓了。多看小地图，才能预判对手的动向，先发制人。

🐉

控龙大师

龙是节奏点，也是经济来源，打野必须会控龙

龙坑是大节奏！不管是主宰还是暴君，打野都要把握好时机。最好是在推完线、队友都有时间的时候开龙。别一个人偷偷打，万一对面来抢，你可能就交代在那了。

💪

保护队友

帮队友建立优势，扩大团队经济领先

打野不是只管自己刷，你要帮队友建立优势。比如射手被压了，你去抓一波让他喘口气；比如法师没线权，你去帮她清一波。帮队友就是帮自己，队友肥了，团战才好打。

⚔️

入侵对面

打乱对面打野节奏，让他没法安稳发育

入侵野区是打野的高级技巧。如果你打得过对面打野，就可以去反他的野怪。比如对面蓝开了，你就去反他的红；或者你清完野区，顺路去对面野区看一眼，能反就反，不能反就骚扰。

💡 打野的黄金法则

  • 节奏比刷野重要，别光顾着刷，忘了搞事情
  • 帮优不帮劣，优先帮优势路扩大优势
  • 多看小地图，少死，多支援
  • 控龙是大事，别忘了在关键时间点拿龙
  • 心态要稳，被反抓了也别崩，继续找机会
02

开局刷野路线

开局的前30秒决定你这局的走向。选对刷野路线，能让你快速到4级，还能顺便搞事情；选错了，可能前期就崩了。

红开路线

路线：红buff → 三熊 → 蓝buff → 河道蟹 → 到4级

适合英雄：需要攻速的打野，比如刘备、雅典娜、娜可露露

优点：红buff提供减速和灼烧，刷野快，到4级后抓下路成功率极高

注意：红开意味着你4级的时候上半野区还没刷，如果对面入侵上单，你支援会比较慢

蓝开路线

路线：蓝buff → 三狼 → 红buff → 河道蟹 → 到4级

适合英雄：需要冷却的打野，比如娜可露露、赵云、暃

优点：蓝buff提供冷却缩减，让你技能CD更快，前期战斗力更强

注意：蓝开到4后通常抓上路或中路，看哪边更好抓

速3路线

路线：buff → 小野 → 另一个buff，快速到3级

适合英雄：前期强势的打野，比如裴擒虎、云中君、橘右京

优点：3级就去搞事，不给对面打野发育时间，打他一个措手不及

注意：风险较高，如果搞事失败，发育会落后很多

反野路线

路线：开局直接去对面野区偷buff，或者配合辅助反野

适合英雄：前期伤害高的打野，比如裴擒虎、云中君

优点：打乱对面打野节奏，还能蹭蹭对面经济

注意：需要看队友配合，单独去反野很容易被包

03

打野类型

不同的打野有不同的玩法，找到适合自己的类型很重要。有的打野需要吃全队经济，有的打野让经济给队友也能赢。

⚔️

野核型打野

代表英雄：澜、镜、暃、娜可露露、李白

特点：吃全队经济，需要大量资源才能打出伤害，后期carry能力极强

玩法：前期蹭线发育，4级后开始抓人，中后期接管比赛，一打五不是梦

适合：喜欢carry、想秀操作的玩家

核心 吃经济 carry
🛡️

蓝领型打野

代表英雄：赵云、猪八戒、曹操、铠

特点：不需要太多经济，技能机制优秀，让经济给队友也能发挥作用

玩法：前期帮队友建立优势，中期开团抗伤害，后期保护队友输出

适合：团队配合型、愿意为队友付出的玩家

团队 抗伤害 蓝领
⚡

节奏型打野

代表英雄：兰陵王、阿轲、云中君、裴擒虎

特点：前期伤害爆表，不断搞事入侵，带起全场节奏

玩法：速3入侵，不给对面打野喘息机会，从头压制到尾

适合：激进打法、喜欢打架、不喜欢刷野的玩家

节奏 入侵 压制
👑

刺客型打野

代表英雄：韩信、百里玄策、孙悟空

特点：高机动性，切后排能力强，但是比较脆，容易蒸发

玩法：绕后切脆皮，打完就跑，不和前排纠缠

适合：操作熟练、喜欢切后排的玩家

刺客 切后 灵活
04

什么时候该做什么

不同时间点有不同的重点，打野要跟着时间走。什么时候该刷野、什么时候该抓人、什么时候该控龙，都有讲究。

1️⃣

1-4分钟：发育期

快速到4级是第一要务！可以顺便抓人，但别耽误刷野节奏

刷野到4级 观察边路 准备首次抓人
2️⃣

4-8分钟：节奏期

到4级后开始搞事情！抓人、控龙、推塔，建立团队优势

优先抓人 控龙（4分钟首龙） 推塔推进 入侵野区
3️⃣

8-12分钟：团战期

团战多了，打野要找机会开团或者切后排，别一个人单机

配合开团 控大龙（10分钟） 推高地塔 保护队友
4️⃣

12分钟后：终结期

游戏后期，打野要么切后排，要么保护队友，一波结束比赛

切后排 保护C位 控龙 终结比赛

⚠️ 时间节点的注意事项

  • 4分钟：小龙刷新，是第一个大节奏点，提前控龙
  • 8分钟：先知主宰刷新，可以召唤小兵推塔
  • 10分钟：黑暗暴君+主宰同时刷新，要拿龙
  • 20分钟：风暴龙王刷新，拿了基本能赢
05

抓人技巧

抓人是打野的基本功，但也是最考验意识的。一个好的抓人，能帮队友建立优势；一个错误的抓人，可能把自己也搭进去。

✅ 好抓的情况

  • ✓ 对面压线太深，靠近我方防御塔
  • ✓ 对面没有闪现或其他保命技能
  • ✓ 我方队友有控制技能
  • ✓ 河道草丛有视野
  • ✓ 知道对面打野不在附近

❌ 不好抓的情况

  • ✗ 对面防御塔下，太深了
  • ✗ 对面有闪现、净化等保命技能
  • ✗ 我方队友没控制技能
  • ✗ 不确定对面打野位置
  • ✗ 对面兵线还没过来

🎯 抓人的正确流程

  • 1. 判断时机：先确认这波兵线是否有利于抓人，对面是否压线
  • 2. 选择路线：从河道走比从塔后绕更快，但要注意是否被视野看到
  • 3. 等技能：等自家队友先交控制技能，你再补伤害
  • 4. 留技能：抓完人别急着走，看看能不能反蹲或者拿龙
  • 5. 推塔：抓死人后赶紧推塔，这是最重要的

🎮 抓人实战案例

场景：你玩娜可露露，4级了，下路鲁班和对面黄忠对线，兵线刚好推到对面塔下

分析：

• 对面黄忠在塔下，位置靠前 ✓

• 兵线进塔，黄忠需要清兵 ✓

• 鲁班有控制技能 ✓

• 对面打野在中路出现了 ✓

正确操作：从河道草丛绕过去，等鲁班先用一技能把黄忠弹开，然后你大招飞过去一套秒掉。击杀后推塔拿龙。

06

控龙技巧

龙是节奏点，也是资源点。控龙做得好，能让团队经济领先；控龙做不好，可能被对面翻盘。

🐲

小龙的用处

4分钟刷新，增加全队经验金币，优势方必拿

小龙最主要的是经验！拿了小龙，全队都能到4级，团战优势巨大。所以4分钟的小龙一定要争，如果打不过，也要骚扰对面打龙，拖延时间。

👹

先知主宰

8分钟刷新，击杀后召唤小兵，帮助推塔

先知主宰主要是推塔用的。拿了之后会不断召唤小兵推线，特别适合优势方滚雪球。如果你们在推塔节奏上，拿了先知主宰能让对面难以防守。

🐉

黑暗暴君

10分钟后刷新，增加全队物理/法术攻击

暴君加的是输出！拿了暴君，全队伤害提升，团战更容易赢。特别是在推高地的时候，拿了暴君能快速拔塔。

🐍

风暴龙王

20分钟后刷新，击杀后获得超强力护盾和真实伤害

风暴龙王是终结比赛的利器！拿了龙王，全队获得护盾和真实伤害buff，可以强行推塔或者打团。这个龙一定要争，没拿到基本就输了一半。

💡 什么时候打龙

  • 推完线，队友都有空的时候
  • 击杀对面打野后，赶紧拿龙
  • 对面人员分散，难以争夺的时候
  • 做好视野，确认对面不在附近
  • 别一个人偷偷打龙，万一被抢了还可能被反杀

⚠️ 打龙要注意

  • 打龙前一定要做好视野！被对面抢龙加团灭是经典翻盘方式
  • 如果对面来人抢龙，果断放弃，别为了龙把自己搭进去
  • 风暴龙王一定要打，但是要注意队友位置，别脱节
07

常见错误

这些错误打野经常犯，犯了轻则崩盘，重则被队友骂到挂机。避开这些坑，你至少是个合格打野。

❌ 只刷野不抓人

刷完野区就走，队友被抓也不管，节奏全丢

→

✅ 刷完野区主动找机会

顺路看看边路有没有机会抓人，或者去反蹲

❌ 无脑入侵被反杀

不看队友位置，一个人冲到对面野区送

→

✅ 入侵前确认队友能支援

入侵是配合的事情，最好有辅助跟着

❌ 不控龙

龙刷了完全不管，白白给对面

→

✅ 主动控龙控资源

设置时间提醒自己龙刷新了，提前准备

❌ 经济落后还抢队友线

自己崩了还吃队友经济，让队友更难受

→

✅ 蹭线但不抢线

蹭线一起吃可以，但别一个人把线全吃了

❌ 不看小地图被抓

不知道对面打野在哪，自己被抓了无数次

→

✅ 多看小地图预判敌人动向

养成习惯，每5秒扫一眼小地图

❌ 抓人失败不撤退

抓人没抓到还继续追，结果被反杀

→

✅ 抓不到就撤，别贪

抓人失败赶紧回去刷野或者控龙，别追到塔下

❌ 团战不切后排

团战和对面前排纠缠，完全不管对面脆皮

→

✅ 绕后切对面脆皮

作为打野，你的任务是击杀对面后排
